# Dependency set for the standalone macOS Telemachos.app.
#
# Two deliberate differences from the server-oriented requirements.txt:
#
#   1. `chromadb` (the full engine) replaces `chromadb-client` (the thin HTTP
#      client). The app runs its vector store in-process - see
#      src/chroma_client.py - because a desktop app cannot ask its user to
#      start a separate ChromaDB service first. The two packages share the
#      `chromadb` import name and must never both be installed.
#   2. The test-only packages (pytest, pytest-asyncio, httpx2) are dropped.
#      They are development tooling and have no business inside a shipped
#      application bundle.
#
# Everything else tracks requirements.txt. Keep them in sync when upstream
# adds a runtime dependency.
