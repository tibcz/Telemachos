How these downloads are kept safe

Every model here is GGUF. That matters: the usual PyTorch .bin and .pt checkpoints are Python pickles and run code when they are loaded, which is how a malicious model actually attacks you. GGUF is plain data with no code path, and Telemachos refuses any other format. Downloads come only from the repositories listed on this page, filenames are resolved from HuggingFace rather than guessed, and every file is checked against the SHA‑256 HuggingFace publishes for it — a mismatch is deleted rather than kept.
